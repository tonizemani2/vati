# The mission
An AI that **predicts the future** — calibrated, falsifiable, **pre-consensus** calls on where scarcity/value migrates, **before it's priced in**. Rent accrues to the binding constraint; the edge is seeing it move first. The scored, leak-free record is the *credibility method*, not the pitch — the product is the prediction. **Pope is the engine spine; everything routes through it.** Value = the human+AI thinking loop over real data; code is thin scaffolding (two folders, one DB).

# THE BAR — read twice
Pre-consensus = the **faint, granular, early** signal nobody has priced.
- **Missing a shift the size of deep learning is total failure, not a caveat.** Go silent on the decade's biggest winner and you are a hindsight narrator.
- Alpha lives in **small intricacies**: a sub-topic gaining share, a few elite labs pivoting, a technique crossing fields, a citation graph reorienting. Aggregate counts are the LAST place a signal shows — read the finest grain.
- **Recall at the detector, precision at the gate.** Fire on many sharp orthogonal early signals; let the supply-graph + consensus gates reject false positives. Never buy precision by going blind to the early move.
- Detect on **slope-of-slope / changepoint + multi-channel leading signals** (citation velocity, cross-field diffusion, talent inflow, structural holes) — not departure from one global trend on annual counts. That blindness hid deep learning.

# The data moat — we are NOT a prompt layer
**Reason agentically over a worldwide data layer**, never free-associate from a prompt.
- Every call walks real data: coverage → measured signals → dependency graph to the inelastic input → priced-in gate. Loop over the substrate; do not read one static dump.
- Hold a **per-layer grade of completion** across the 9-layer spine (frontier → … → outcomes). Know where we are rich vs blind; thin layers (demand, outcomes, supply-elasticity, patents) are the build priority. No joking about coverage.
- **Show it publicly**: a living visual of what we collect, globally, over time — proof we predict from data.

# Distribution = content, zero AI trace
- **Visual-first everywhere** — charts and diagrams as evidence, not decoration. Beautiful, on-brand (indigo / Gt Standard) scroll-stoppers, never simplistic memos.
- Every public word goes **research-draft → humanizer scrub** (AI-tell ≤ 15, no em-dashes, no slop). The brand sells being right; sloppy copy makes a winner read like a fraud.
- **Capture**: each surviving call carries a concrete forecast → revenue path — who to call, the ask, who pays.
- **Chat has modes**: talk, forecast, capture, web-search, walk-the-data — all data-grounded, not one trick.

# How to behave (non-negotiable)
Leak-free or worthless (a row's real date ≠ fetched_at) · GIGO gate (no source without a trust rationale) · cost gate (keyless first; log spend; any >$0 or Opus run = ask first with agent count + estimate) · forecasts immutable + falsifiable · ask on pivotal forks · minimalism (justify every dep; prefer deleting) · commit to the side the evidence favors and mark where it ends. Be concise; lead with the answer.
